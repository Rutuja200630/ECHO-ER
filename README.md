# ECHO-ER Project

Evidence-Consistent Hybrid Optimization for Entity Resolution.

## Overview
This repository contains the full end-to-end Machine Learning pipeline for a Kaggle Entity Resolution / Entity Matching challenge.

The pipeline implements the ECHO-ER architecture, balancing high precision and robust recall by leveraging both Sparse and Dense retrievers, followed by an advanced Evidence Engine and a LightGBM classifier.

## Directory Structure
- `data/` - For datasets and metadata (Note: Data loading is done on Kaggle)
- `docs/` - Project documentation, master plans, and analysis reports
- `src/` - Python modules and scripts for the ML pipeline
- `notebooks/` - Exploratory analysis (if any)
- `output/` - Processed artifacts and submission files
